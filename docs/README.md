# Documentation

Read in this order the first time; jump straight to a reference afterwards.

| document | read it when |
|---|---|
| [getting-started.md](getting-started.md) | you want a first answer about your own code in ten minutes, with the exact commands and their expected output |
| [agent-guide.md](agent-guide.md) | an AI agent will set flowtrace up or use it; includes the block to paste into the agent's instructions |
| [concepts.md](concepts.md) | you want to know what facts, the flow, a walk, seeds and evidence tiers mean |
| [cli.md](cli.md) | you need every command and flag; it is `flowtrace --help`, verbatim |
| [configuration.md](configuration.md) | you are editing `flowtrace.config.json`: every key, every repository kind |
| [../areas/README.md](../areas/README.md) | you are writing an area file, the denominator every coverage number stands on |
| [fact-schema.md](fact-schema.md) | you are reading `out/facts/*.json` directly or extending an extractor |
| [scout.md](scout.md) | you want the optional code index that extends the walk past `graph: unavailable` |
| [benchmarks/](benchmarks/README.md) | you want to know how this compares to the tools you could install instead, and how that was measured |

The CHANGELOG is at the repository root; so are [CONTRIBUTING.md](../CONTRIBUTING.md) and
[SECURITY.md](../SECURITY.md).
